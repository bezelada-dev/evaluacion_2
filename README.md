# Evaluacion2 - Software de Geolocalización y Guía de Rutas

Este repositorio contiene la solución desarrollada para la Evaluación Parcial N° 2 de la asignatura **Telepresencia y Entornos Innovadores de Colaboración Humana (CUY6142)**.

## Descripción del Proyecto
El proyecto consiste en una aplicación desarrollada en Python que consume la API de **Graphhopper Directions** para planificar rutas entre dos puntos elegidos por el usuario, ofreciendo:
- Interacción y mensajes completamente en español.
- Salida numérica formateada a dos decimales (distancia en km y tiempo estimado).
- Narrativa e instrucciones del viaje paso a paso.
- Opción de salir del programa ingresando `s` o `salir`.

## Requisitos
- Python 3.x
- Librería `requests` (`pip install requests`)
- Una clave API (API Key) activa de Graphhopper
